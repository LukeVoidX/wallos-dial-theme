# 管理分类

[简体中文](CATEGORIES.zh-CN.md) · [English](CATEGORIES.md)

从「**订阅 → 管理分类**」进入，也可以打开「**设置 → 分类 → 管理分类**」。每个账户只管理自己的分类。安装 Dial 不会改动已有的 Wallos 分类或订阅归属。

## 日常操作

- **新增、改名：**输入 1–60 个字符后保存。分类名称属于用户数据；切换界面语言不会自动翻译名称。
- **排序：**拖动行首手柄，或用键盘操作「上移」「下移」按钮。受保护的默认分类如存在，会留在第一位。
- **合并：**选择目标分类，先查看受影响的订阅数量，再确认。订阅 ID、金额、付款日期、付款方式和上传的 Logo 都保留；只更新 `category_id`，然后移除来源分类。停用及一次性订阅也会一并转移。
- **删除：**空分类可以确认后删除。有订阅引用时，先合并；受保护的默认分类不能删除。

## 可选的初始分类

账户**完全没有订阅**时，可以选择「使用初始分类」。预览只补齐缺少的 **AI、Infra、Domains、Media**。可移除的现有空分类会逐项列出，删除选项默认全部不勾选；请在确认前核对具体名称。受保护的默认分类会保留。这项操作是可选的，不会自动覆盖现有订阅账本。

如果另一个标签页在确认前修改了分类或新增了订阅，旧预览会被拒绝；重新打开预览，核对当前列表即可。

[公开 Demo](https://wallos-demo.mostai.org/) 可以查看虚构分类，但不能修改。要管理自己的分类，请安装[固定版本的 Dial 镜像](../README.zh-CN.md#新安装)。Demo 的四个分组只是示例数据，不会强制写入你的账户。
