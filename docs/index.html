Self-hosted installation

Start with a versioned image.

The repository's Compose file pins ghcr.io/lukevoidx/wallos-dial:1.0.0 and binds HTTP to 127.0.0.1:8282. You control access, data and updates.

New installation guide ↗

git clone https://github.com/LukeVoidX/wallos-dial-theme.git
cd wallos-dial-theme
docker compose up -d

Open http://127.0.0.1:8282 on the Docker host. If you already have a Wallos ledger, back up its SQLite database and uploaded Logo volume, check the resolved Compose mounts, and rehearse the upgrade on copies before switching.

Clear answers

Before you switch.

Is this an official Wallos theme?

Wallos Dial is an independent GPLv3 source overlay built into a Docker image. It is not affiliated with Wallos or an in-app theme switch.

Will it follow every Wallos update?

1.0.0 is built and tested for Wallos 5.8.3. A newer upstream version requires a compatibility review and a new Dial image.

Can I change data in the public Demo?

No. Its 30 records are fictional and the public routes are read-only. You can inspect categories there; category edits and icon uploads require your own installation.

What happens to my existing Logos?

The original Wallos Logo file remains available. Select Original to display it again. Back up the Logo volume and SQLite database before upgrading.

Can I upload SVG files?

My Icons accepts constrained SVG, PNG, JPEG and WebP uploads. SVG files are validated and converted to PNG; the account library has size and count limits. Read the limits ↗

Does language switching translate my data?

The interface language changes. User-entered subscription names, categories and notes remain as entered.
