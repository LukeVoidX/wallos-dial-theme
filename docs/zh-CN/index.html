设计思路

订阅支出，清楚有序。

暖白底、黑色数字、精确日期刻度与少量红色，贯穿桌面应用。下方均为使用虚构数据拍摄的 1.0 实际界面。

01 / 条理

让订阅清单更有秩序。

分类卡片便于浏览长列表，搜索、筛选、排序、列表和网格视图依然可用。自行安装后，可以按自己的订阅建立分类。

查看完整尺寸截图 ↗
02 / 掌控

分类可以自己管理。

新增、改名、排序和合并分类，不必重新录入订阅。空分类可以删除；可选的初始分类不会覆盖现有账本。

03 / 识别

每项订阅都能选择图标。

保留原有 Wallos Logo、选择九枚统一绘制的中性图标，或上传私人图片到「我的图标」。每项还可设置有无边框、彩色或单色，以及 80%–120% 的大小。

04 / 视角

数字清楚，细节也在。

日历和统计沿用总览的字体层级与配色。总额先行，需要深入时再查看分类分布与支出预测。

按自己的方式使用

熟悉的操作，更多自主空间。

管理分类

按账户新增、改名、排序、合并和删除空分类。分类说明 ↗

选择图标样式

原有 Logo 会保留；内置图标为原创中性符号，「我的图标」只属于当前账户。图标说明 ↗

保留 Wallos 操作

继续新增、编辑和管理订阅，在列表或网格中搜索、筛选、排序；通知与设置功能仍可使用。

切换界面语言

支持英文、简体中文、繁体中文及 Wallos 的其他语言。自行填写的名称和备注保持原样。

备份两处数据

「我的图标」保存在 SQLite，原有上传 Logo 保存在 Logo 数据卷。升级前请同时备份。

固定兼容版本

1.0.0 固定适配 Wallos 5.8.3。上游推出新版本后，需要再发布经过审查与测试的 Dial 镜像。

自行部署

从固定版本开始。

仓库的 Compose 文件固定使用 ghcr.io/lukevoidx/wallos-dial:1.0.0，默认只监听 127.0.0.1:8282。访问权限、数据和更新由你自己管理。

中文新安装说明 ↗

git clone https://github.com/LukeVoidX/wallos-dial-theme.git
cd wallos-dial-theme
docker compose up -d

在运行 Docker 的机器上打开 http://127.0.0.1:8282。若要接入原有 Wallos 账本，请先备份 SQLite 数据库和上传的 Logo，核对 Compose 挂载路径，并在数据副本上排练迁移与回退。

常见问题

切换前需要知道的事。

这是 Wallos 官方主题吗？

Wallos Dial 是独立开发的 GPLv3 源码叠加层，构建为 Docker 镜像；不隶属于 Wallos，也不是应用内置的主题选项。

Wallos 更新后会自动兼容吗？

1.0.0 针对 Wallos 5.8.3 构建和测试。新的上游版本需要兼容检查和经过验证的新镜像。

在线 Demo 可以修改数据吗？

不能。30 条记录均为虚构，公开路由只读；可以查看分类，但修改分类和上传图标需要自行安装。

已有 Logo 会丢失吗？

原有 Wallos Logo 文件会保留，选择「原图」即可再次显示。升级前要备份 Logo 数据卷和 SQLite 数据库。

可以上传 SVG 吗？

「我的图标」接收受限制的 SVG、PNG、JPEG 和 WebP。SVG 经检查后转为 PNG；私人图标库有数量和容量上限。查看具体限制 ↗

切换语言会翻译已有数据吗？

界面标签会切换语言；用户填写的订阅名称、分类和备注保留原文。
