## Short recommendation

**For a self-hosted Wallos user who wants a calmer desktop ledger:** Wallos Dial is worth trying on a backed-up, disposable copy of a Wallos 5.8.1 installation. The dashboard brings cost and upcoming dates together; the subscriptions page adds category grouping while keeping the original workflows. It installs as a versioned Docker overlay. Check your existing mounts and access controls before switching a live service.

## Announcement draft

> I built Wallos Dial, a desktop-focused visual theme for Wallos 5.8.1. It adds a date dial, payment countdown, grouped subscription ledger, calmer statistics, and a quick language selector. The repository includes installation, rollback, and compatibility guidance plus direct before/after captures using synthetic data. It is an independent GPLv3 overlay, not an official Wallos theme option. A newer Wallos release needs a tested Dial update before upgrading.
