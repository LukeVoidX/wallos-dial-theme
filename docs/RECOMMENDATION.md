## Short recommendation

**For a self-hosted Wallos user who wants a calmer desktop ledger:** after the 1.0 image is published, try Wallos Dial on a backed-up, disposable copy of a Wallos 5.8.3 installation. The dashboard brings cost and upcoming dates together; the subscriptions page adds category management and account-scoped icon choices while keeping the original workflows. It installs as a versioned Docker overlay. Check your existing mounts and access controls before switching a live service.
