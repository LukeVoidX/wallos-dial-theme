# Poster source and provenance

- `hero-backdrop.jpg`, `compare-backdrop.jpg`, `features-backdrop.jpg`, `showcase-backdrop.png`, and `calendar-stats-backdrop.png` were generated with OpenAI ImageGen for this release. They contain no application interface, text, or third-party logos. The last was prompted as a warm ivory material study with subtle instrument calibration details and a quiet center for compositing actual UI captures.
- `posters.html` arranges those backgrounds, typeset copy, and the direct browser captures in `../../screenshots/`. The comparison screenshots remain exact pixels from the demo browser, scaled by CSS; no model was asked to invent or alter UI details.
- Render at a 1920×1080 browser viewport with `?kind=hero`, `dashboard`, `subscriptions`, or `features`. Render `?kind=social` at 1280×640 for the GitHub repository's social preview. The resulting files live one directory above.
- The dedicated showcase variants are `?kind=showcase-overview`, `showcase-subscriptions`, `showcase-calendar`, `showcase-statistics`, and `principles`. Their UI panels contain exact synthetic-data browser captures from Wallos Dial; the principles poster contains deterministic text and palette samples.
- The demo account was isolated from production. It used fictitious subscription names, prices, user details, and generated monogram logos. The raw captures are included so readers can inspect the UI without poster framing.
- `campaign.html` produces the six-part English and Simplified Chinese series with `?kind=hero|time|ledger|calendar|numbers|demo&lang=en|zh` at 1920×1080. `instrument-dial-backdrop.png` was generated with OpenAI ImageGen from this prompt: “A premium editorial macro photograph of a fictional precision instrument dial, warm ivory matte enamel, fine black calibration ticks, one deep red indicator, brushed aluminium rim at the far right, soft studio light, open negative space; no words, logos, screens or UI.” All text, counts, screenshot crops and layout are deterministic HTML/CSS.
- Campaign screenshot sources are `after-dashboard.png` for the 16-record English hero/date-dial examples, `real-demo-overview.png` for the 30-record Chinese equivalents, plus `campaign-grid-{en,zh}.png`, `campaign-calendar-oct-{en,zh}.png`, `campaign-stats-{en,zh}.png`, and `campaign-demo-overview-{en,zh}.png` for the 30-record public-demo examples. The new public-demo captures were taken at a 1600×1000 CSS viewport on 2026-09-28. They contain fictional data. See [`../../../CAMPAIGN.md`](../../../CAMPAIGN.md) for the poster-to-feature mapping and presentation references.
