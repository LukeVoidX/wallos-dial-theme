# Wallos Dial public icon catalog

All nine SVGs in this directory are original, neutral pictograms drawn for Wallos Dial 1.0. They share a 24 × 24 viewBox, transparent background, #191817 strokes at 1.7 units, round caps and joins, and intentionally modest optical corrections in `catalog.json`. The red accent is reserved for application states; the service pictograms remain monochrome.

The nine keys identify services for icon selection and preserve existing preferences. The images are generic concepts rather than representations of those services' logos. No third-party brand artwork or private owner mark is embedded in this public catalog.

**Artwork provenance:** first-party Wallos Dial pictograms authored for this repository. Each `source_url` in `catalog.json` points to the artwork file in the public source tree. These files are offered under the repository's GPLv3 license. The service names remain the property of their respective owners; using a name as a chooser label does not imply endorsement or grant rights to use that service's official mark.

The original Wallos `subscriptions.logo` file remains untouched. A private installation can select its own uploaded images or legacy Logo separately from this catalog. Private artwork is excluded from the public package.
